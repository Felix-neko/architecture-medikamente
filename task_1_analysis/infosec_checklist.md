# Аудит информационной безопасности компании «Медикаменте»

Здесь я взял старый контрольный список по ИБ из 5-го спринта и попросил товарища Claude Opus немножко его доработать: добавить пункты, специфичные именно для медицины и для нашего случая. 

Ответы сгенерировал с помощью Claude Opus, а потом честно вычитал и подверг ручной доработке согласно своим представлениям о прекрасном.
